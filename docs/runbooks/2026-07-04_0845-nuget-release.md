# Runbook: NuGet release

**Статус:** актуально  
**Создан:** 2026-07-04 08:45 (UTC+3)

Публикация пакетов `IntegrationFlow.*` на NuGet.org через GitHub Actions.

---

## Предварительные требования

1. Аккаунт на [nuget.org](https://www.nuget.org/)
2. Зарезервированные Package ID:
   - `IntegrationFlow.Core`
   - `IntegrationFlow.EntityFrameworkCore`
   - `IntegrationFlow.Metrics.OpenTelemetry`
3. GitHub Secret `NUGET_API_KEY` (scope: Push для `IntegrationFlow.*`)

---

## Checklist релиза

1. Все тесты зелёные на `master` (CI: unit + integration + pack)
2. Обновить [`CHANGELOG.md`](../../CHANGELOG.md)
3. Создать и push tag:

   ```bash
   git tag v1.0.1
   git push origin v1.0.1
   ```

4. Workflow [`.github/workflows/release.yml`](../../.github/workflows/release.yml) публикует `.nupkg` и `.snupkg`
5. Проверить страницы пакетов на nuget.org (версия, README, dependencies)

---

## Ручной release (workflow_dispatch)

1. GitHub → Actions → Release → Run workflow
2. Указать SemVer версию (например `1.0.1`)

---

## Локальная проверка pack

```bash
dotnet pack IntegrationFlow.sln -c Release -o ./artifacts
```

CI на каждый push собирает pre-release artifact: `1.0.0-ci.{run_number}` (не публикуется на NuGet.org).
